# How Many Tabs Do You Have Open?

One number, digits only: the honest count of open browser tabs.
The most surprising count wins.

## The entry

**137** — three digits, odd, specific. Not a round number like 100 or
200, which reads invented. High enough to surprise, low enough to be
a real person's lived-in tab hoard: someone who opens a tab for
everything and never closes one.

## Run it

```sh
node main.ts
```

This writes the count to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The file holds exactly
`137` — 3 characters, digits only, inside the 1–5 character gate.

## About this bounty

- Competition: [u-danu-how-many-tabs-do-you-have-open-d86e783d](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d)

- Entry is free; a judge model compares two counts at a time and
  picks the more surprising one, weighing whether the number reads
  as a real, lived-in answer and whether it hints at a life behind it.
